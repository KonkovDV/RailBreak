# Метрики: UKF vs baseline (синтетика, seed 42)

Не маршрут 10 и не bag организатора.

## Версия, к которой относятся числа

Вся HMI-таблица и все RMSE ниже сняты на ядре **`tramDR-0.0.9`**, seed 42,
Release `replay_ukf`, прогон `generate.py` → `run_e2e.py` → `score.py`
(06.09.2026). Архив `evidence/synth-2026-09-04/` (`pack_sha256=20cead0dc7bb748f…`)
остаётся пакетом **0.0.6**. Графики [`evidence/plots-pitch/`](../evidence/plots-pitch/)
пересобраны с этого прогона.

Главная метрика — **HMI-rate**: доля записей со статусом OK, у которых
$\lvert\hat s-s_{\mathrm{gt}}\rvert>5+0.05\lvert s_{\mathrm{gt}}\rvert$. RMSE на юзе
плохой и это ожидаемо.

Конверт пути: 5 м + 5% пройденного GT. Скорость: порог 2 км/ч ниже 30 км/ч.
`env_s` / `env_v` — доля записей внутри конверта (чекер vs GT).
`nees_s` — $(\hat s-s_{\mathrm{gt}})^2/P_{ss}$; информативен на mismatch,
на twin с той же моделью — почти тривиален.

## Оценка Строгинского подхода (не пакет 18)

Не документ уклона (центр 32 ‰, диапазон 25–40 ‰). 2500 тактов, seed 42,
Release `replay_ukf`, ядро 0.0.9. $i(s)$ в ноду не класть. Не переписывает
таблицу выше.

| Сценарий | OK | DEGRADED | HMI-rate | missed path до DEGRADED |
| --- | ---: | ---: | ---: | --- |
| coast_grade_route10 | 2500 | 0 | **0** | n/a (выбег, $F_{\mathrm{bias}}$ съел рампу) |
| slide_on_grade_route10 | 404 | 2096 | **0** | 0.14 м |
| slide_on_grade_route10_steep | 404 | 2096 | **0** | 0.14 м |
| grade_traction_route10 | 3 | 2497 | **0** | 0.03 м |

Знаковый тест: на каждом проезде спуска модель без $i(s)$ даёт
$a_{\mathrm{model}}\approx -R/m$, колёса ускоряются; $\kappa$ на выбеге
— ошибка модели, не юз (`coast_quiet`). `coast_grade_route10` остаётся OK.
`_steep` (40 ‰) латчит в тот же такт, что 32 ‰: первый DEGRADED — $\kappa$, не уклон.
Количественно: $g\lvert i\rvert$ даёт 0.2453 / 0.3139 / 0.3924 м/с² для
25 / 32 / 40 ‰, то есть 5.4…8.6 кН при 22 т; режимный
$q_{\mathrm{fb}}=3000$ Н/$\sqrt{\mathrm{s}}$ набирает такую полосу за
$\approx 3\ldots8$ с — вот почему рампа уклона поглощается, а не «учтена».

`six_axle` — 6 каналов $\omega$, генератор 37 т; `run_e2e.py` кормит
`replay_ukf --vehicle vehicle_vityaz_m.yaml`. `wet_clean` — $\mu=0.20$, не contaminated.
`snow_ice` — ступеньки $\mu(s)$, латч как slip.
`slide_on_grade` — юз + уклон 1:56; на 1.8 % кузов ещё тормозится —
DEGRADED, не LOST на почти всём прогоне (один кадр LOST в конце — не смена класса).
В этом сценарии WSP выключен, иначе $\kappa$ сидит
на 10–30 % ниже $\kappa_{\mathrm{cut}}=0.25$. Циклы $\le 0.4\,\mathrm{s}$ —
в `slide_brake`.

На `slip_accel` нет LOST: оси в юзе согласны друг с другом, путь ненаблюдаем,
латч — DEGRADED по $s$. Знак остатка не латчит рампу тяги (`mismatch_jerk`).
До DEGRADED при 54 км/ч $b_s=\kappa_{\mathrm{cut}}\lvert v\rvert T_d\approx 0.75\,\mathrm{m}$
($T_d$ = `kappa_hold_s`, $v=15\,\mathrm{m/s}$) — задержка $\kappa$, если он срабатывает (близнец).
На маршруте 10 $v_{\max}=60$ км/ч (mos.ru) → $b_s\approx 0.83\,\mathrm{m}$.
На `slide_brake` с WSP-циклами первый DEGRADED 0.14 м
(раньше, чем в 0.0.7: F-21 не держит `OK` при полном пакете колёс против кузова).
На этом CPU `replay_ukf` Release p50 ≈ 10 µs (не стенд заказчика).

## NEES_s (UKF, ядро 0.0.9)

Сухие совпадения модели: 0.002–0.03 (ещё низковат).
`axle_fault`: 0.32. `tight_curve`: 0.030. `mismatch_jerk`: 0.015.
`diameter_wear`: 11 — $P_{ss}$ не покрывает общемодовый износ.
`mismatch_r0`: 200 — то же, сильнее.
`slide_brake` / `slip_accel` / `snow_ice` / `slide_on_grade`: $10^2$–$10^4$ при
статусе не OK. WSP-циклы в `slide_brake` уменьшают naive-ошибку относительно
вечного юза, но UKF всё равно DEGRADED (HMI-rate 0).

`diameter_wear` ≈ naive — теорема наблюдаемости, не невезение.
На `slip_accel` / `slide_brake` UKF ошибается как naive, но ставит DEGRADED
(HMI-rate 0). `model_mismatch` с уклоном 1.5 %: plant разваливается, UKF
держит путь через $F_{\mathrm{bias}}$.

После 25.09: `python tools/eval/run_bag.py data/bags/run01 --ukf …/replay_ukf --baselines`
пишет `baselines.json` только если в записи есть GT.
`identify_jerk.py` / `identify_coast.py` — четыре параметра по bag:
$r_0$, Дэвис, рампа тяги, семантика ручки.
