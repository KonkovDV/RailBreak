# Red Team — непрокоммиченное ядро tramDR-0.0.10 — 07.09.2026

Адверариальный проход по рабочему дереву **до** релиза `tramDR-0.0.10`.
База сравнения: `main` = `1aed325` (`tramDR-0.0.9`). Предмет — пакет
`RB08-01`…`RB08-32` плюс дыры, которые этот пакет мог оставить.

Метод тот же, что 06.09: искать **OK на уже неверном $\hat s$/$\hat v$** и
**правдоподобный ноль вместо отсутствующих данных**. Новые идентификаторы —
`RT10-*` (не пересекаются с `F-21`…`F-36` и `RB08-*`).

Формулировка «ошибок нет» не используется.

---

## Краткое резюме

1. Класс HMI-OK-на-неверном пути, ради которого писали RB08-01/02, в ядре
   держится: forced ZUPT при $|v|\ge 0.35$ и `reject()` защёлкивают
   `path_integrity_latched`; сброс только `reset()`. Агрегат и `confidence_s`
   не возвращаются в OK. Короткий замок нулей (0.32 с) по-прежнему не ZUPT
   (F-01 не открывали).
2. Найден и закрыт **P1 того же класса, что RB08-04**, но на офлайн-пути,
   которым снимают метрики: `replay_ukf` выдумывал $\Delta t=0.001$ на
   дубликате/регрессе штампа и на хвосте catch-up (`RT10-01`). Нода после
   catch-up отбрасывала leftover $< dt_{\min}$; `floor(dt/dt_{\max})$ мог
   дать хвост 0 и выкинуть кадр колёс. Исправлено в этом же дереве.
3. Остальное из RB08 при чтении горячих путей совпадает с заявленным
   контрактом. Новые P0 не найдены. Юридические пп. 14.4–14.6 и bag
   организатора 25.09 кодом не закрываются.

## 2. Охота: OK на неверном пути

### 2.1 Path latch (RB08-01/02) — закрыто как спроектировано

Forced ZUPT при $|v|\ge 0.35$ ставит `path_integrity_latched_`. Выход из
гейта снимает `zupt_estimate_disagree_`, но **не** защёлку пути.
`classify`: latch входит в `s_unbounded`, `degraded` и `confidence_s`.
`confidence_v` может остаться OK — это разделение каналов («восстановленная
скорость не есть восстановленный путь»), не ложь агрегата. Чекер и
`replay_ukf` пишут поле `confidence` = агрегат.

`reject()` защёлкивает путь и при $0 < dt \le kMaxStepS$ растит $P_{ss}$ на
$(\max(|v|,1)\,dt)^2$. После численного отката `*this = previous` затем
снова `reject()`: инфлейшн идёт по **восстановленному** состоянию. Это
намеренно (неизвестный путь), не HMI-OK.

0.32 с нулей на выбеге не защёлкивает путь. Не трогать.

### 2.2 `RT10-01` P1 — выдуманный dt в `replay_ukf` (закрыт)

До правки:

* `dt <= 0` или неfinite → `dt = 0.001` и шаг с колёсами;
* leftover catch-up `< 0.001` → то же.

Дубликат строки CSV давал лишний метр пути $\approx v\cdot 0.001$ при
статусе, который мог остаться OK. Это тот же класс, что RB08-04, на пути
`generate → replay_ukf → score`, которым живут `docs/metrics.md`.

После правки: дубликат/регресс — `continue` без шага; leftover $> 0$
применяется как есть. Первый кадр по-прежнему якорит $0.02\,\mathrm{s}$
(офлайн-эквивалент ROS-anchor, но с одним шагом; менять без пересъёма
метрик нельзя).

Нода: leftover после catch-up на measurement-path применялся как `return`
без шага. Плюс `floor(dt/dt_max)` на кратном зазоре давал leftover 0 и
выкидывал кадр колёс. Catch-up теперь `while (dt > dt_max)`, leftover в
$(0, dt_{\max}]$, хвост $< dt_{\min}$ на измерении применяется.

### 2.3 Публикация и split-каналы (RB08-05) — закрыто как спроектировано

`publish_state` не сбрасывает `input_fault_`. Агрегат LOST тянет
`confidence_v/s` в LOST. `Odometry` не несёт OK/DEGRADED/LOST: целостность
на `/tram/diagnostics`. Чекер bag без диагностики не изобретает OK
(RB08-20). Подписчик, который читает только pose, обходит HMI — это
контракт топика, не новый дефект ядра (`RT10-03`, P2 R).

### 2.4 Ручка и тормоз (RB08-06)

Старт ноды: `brake_valid = notch_valid = false`. Тормоз стареет даже без
ручки. Значение по умолчанию в `types.hpp` (`true`) остаётся для CSV/тестов;
новый C++-вызывающий без явного `false` получит «валидный ноль». Ловушка
API, не нода (`RT10-04`, P2 R).

### 2.5 Watchdog / проектор (RB08-07/08)

Heartbeat только `status.name == "tram_dr"`. `age_s < 0` → STALE.
Проектор: неfinite $s$, $P_{ss}<0$, возраст по штампу оценки, штамп оценки
сохраняется, нет публикации при `project_s == false`. Совпадает с заявленным.

`dt_floored_` на skip дубликата врёт именем счётчика (`RT10-02`, P2) — не
HMI-OK.

## 4. Что подтвердилось из RB08 без новой дыры

`project_pd(false)` копирует вход и восстанавливает. Freeze — время, кольцо
128. Passive brake не реверсирует. Канал A шагает `plant_step` с PT1.
`W_c^{(0)}\ge 0` — достаточная политика, `validate_ukf` зовёт
`weights_psd_ok`. Vehicle YAML последним в launch. Notch encoding: Combino
auto без изменений.
