# Контакт: сила при ограниченной скорости колеса

Baseline: `38f65c1912ffc6ac4598f949f88af4e7e0cb6f8c`.
Fix: `907f40b` на `main` (черри-пик [PR #7](https://github.com/KonkovDV/RailBreak/pull/7)).
Один дефект раннего выхода `_implicit_wheel_omega`; online UKF не изменён.

## Воспроизводящий вход

- omega = 100 рад/с, v = 35 м/с, r = 0.35 м, T = 0 Н·м;
- dt = 0.02 с, J = 60 кг·м², Q = 50000 Н, mu0 = 0.35;
- остальные параметры — `PlantParams()`.

Начальное скольжение равно нулю и Newton residual равен нулю. Старый код
возвращал ограниченное omega=80 рад/с **вместе с прежней силой F=0**.
Но при возвращённом omega и том же входном v скольжение уже −7 м/с:
Polach даёт −7120.200006481838 Н. Сила и скорость описывали разные состояния.
Это намеренный граничный вход вне ограничения omega, не режим нормального
трамвайного движения и не новый результат точности на маршруте.

Исправление пересчитывает силу только если ограничение изменило omega.
При отсутствии clipping используется уже вычисленная F; дополнительные
вызовы контактной функции на обычном раннем выходе не добавлены.
Речь о согласованности с **переданной скоростью кузова v**, а не о fully
coupled решении нового состояния кузова и всех колёс.

Четыре теста Polach сверяют известные значения (9), значение (11) при
epsilon=1, малокриповый наклон (12), знак/симметрию/ограничение силы.
Четыре теста возврата покрывают ранний clipping, равновесие внутри диапазона,
сохранение прежнего no-op при dt<=0 и насыщенный fallback без корня.

Источник: [O. Polach, Wear 258 (2005), 992–1000](https://www.oldrich.polach.ch/data/object_4/Wear_2005.pdf),
DOI 10.1016/j.wear.2004.03.046, (4)/(9)/(11)/(12).
При малом скольжении и фиксированных допустимых параметрах наклон кода:
`(kA+kS)/2 * G*a*b*c11 / max(abs(v), v_eps)`.
Регуляризация около v=0 — расширение кода, не измерительная валидация статьи.

## Что не исправлено этим patch

- Clipping может нарушать равенство unconstrained Backward Euler: новый
  тест явно показывает ненулевую невязку при насыщении. Согласованная сила
  не превращает такое состояние в найденный корень.
- Не доказаны полный finite/range domain, единственность нелинейных корней,
  сходимость partitioned/coupled ODE и energy stability интегратора.
- `-F*slip<=0` относится к мгновенной мощности пары контакта, не к энергии
  полной дискретной модели вагона.
- Проверка tanh внутри solver — контракт функции; генератор выбирает для
  tanh отдельную explicit-ветку, которая этим patch не меняется.
- Типовые параметры Polach не идентифицируют конкретный вагон. WSP 0.4 с
  остаётся инженерным параметром: нормативный пункт и применимость не сверены.
- ROS runtime graph, реальные записи, контроллер и HIL не проверены этой порцией.
