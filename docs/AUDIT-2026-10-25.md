## Рекомендации без изменения поведения

- **Медиана пачки RTK.** Сейчас берутся независимые медианы широты, долготы и времени пачки. На кривой это даёт точку чуть внутри дуги. Медиана продольных невязок каждого фикса, перенесённых по дуге фильтра, точнее и не зависит от формы пути.
- **Сетка штампов.** `velocity_resample` и `position_stamp_grid` наращивают время сложением шага; накопленная ошибка на отрезке до 1 с — порядка 1e-15 с. Индексная форма `t0 + i·step` убирает и её.
- **`degrade_recover_s`.** Нода объявляет 1.0 с, граница целостности подгонялась с 0; влияет только на возврат из нестартовых деградаций.

## Ложные срабатывания анализаторов

- cppcheck `danglingTempReference` в `test_core.cpp`: цикл идёт по члену `ready` временного `ReorderDrain`; привязка ссылки к подобъекту временного объекта продлевает его жизнь.
- cppcheck `negativeIndex`: обращение `gt[hole − 1]` защищено условием `hole >= 6` слева от `&&`.
- clang-tidy `bugprone-branch-clone` в `source_quality.hpp`: порядок ветвей задаёт приоритет вида отказа.

## Как воспроизвести

```bash
scripts/jury.sh core                                   # test_core: 472 проверки
cmake -S railbreak_backup_odometry/tools -B build/asan -DCMAKE_BUILD_TYPE=Debug \
  -DCMAKE_CXX_FLAGS="-fsanitize=address,undefined -fno-omit-frame-pointer"
cmake --build build/asan && ctest --test-dir build/asan --output-on-failure
python3 tools/organizer/test_odometer_config.py
python3 tools/eval/lint_claims.py
```
