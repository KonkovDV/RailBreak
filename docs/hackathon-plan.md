## 0. Контракт исполнителя

Роль: инженер по оцениванию состояния и продольной динамике рельсового
транспортного средства, одновременно внутренний Red Team. Работать по-русски.
Каждое опубликованное число сопровождается commit, данными, seed и командой.

1. Сначала доказательство, потом заявление. Абстракт статьи не переносится
   на наш фильтр. Статус чтения каждой ссылки — в §11.
2. Изменение поведения фильтра — только за флагом конфигурации. При значениях
   по умолчанию конвейер `generate.py` → `run_e2e.py` → `score.py` обязан
   воспроизвести [metrics.md](metrics.md): в основной таблице HMI=0 у 18/19,
   `mismatch_r0` = 0.515. Смена умолчаний требует пересчёта таблиц и подъёма
   `kModelVersion` в `tram_dr_localization/include/tram_dr_localization/types.hpp`
   вместе с `tram_dr_localization/package.xml`.
3. Задача закрывается тестом (CTest или unittest) и строкой
   [CHANGELOG.md](../CHANGELOG.md): что изменилось, чем проверено, что открыто.
4. Записи организатора делятся на train / val / test до любого тюнинга.
   Test используется один раз. Эти записи в git не коммитятся.
5. Среда: Windows + MSVC (`cmake --build … --config Release`, бинарь
   `standalone/build/Release/replay_ukf.exe`); CI — Ubuntu, GCC, ASan/UBSan,
   ROS 2 Humble. Четыре job описаны в `.github/workflows/ci.yml`.

Порядок чтения перед правкой ядра: этот файл → [math.md](math.md) §1–7 →
`tram_dr_localization/src/lib/ukf.cpp` (`predict_and_update`, `update_wheels`,
`classify`) → `tram_dr_localization/src/lib/plant.cpp` →
`tram_dr_localization/src/nodes/state_estimator_node.cpp`.

## 1. Постановка

### 1.1 Задача организатора

Официальный текст трека на [mt-hackathon.ru](https://mt-hackathon.ru/)
(сверено ): адаптивная нелинейная математическая модель
(«аппроксиматор») и пакет ROS 2, которые по внутренним данным — положение
ручки контроллера и одометрия колёс — резервно вычисляют скорость и положение
трамвая без GNSS и инерциальных систем. Учитывать проскальзывание, отказы
датчиков, дрейф параметров; публиковать поток координат и скорости в реальном
времени. Состав жюри включает руководство МТТЕХ (беспилотный транспорт,
наземный транспорт, прикладные сервисы), SberAI Lab и МГУ.

Календарь этапов — в Положении. Загрузка решения до 23:59 МСК.
В каждом треке 500 / 300 / 200 тыс. руб.
Внешний разбор критериев (10×1–5) — в
[external-redteam.md](review/external-redteam.md);
нумерацию сверить с действующим Положением, текст PDF которого в репозитории
не извлечён.

### 1.2 Формальная задача

Пусть \(s\) — продольная координата вдоль оси пути, \(v=\dot s\). Наблюдаются
команда \(u_k=(n_k,b_k)\) и угловые скорости \(\omega_{i,k}\), \(i=1..n_w\le 6\).
GNSS, IMU и лидар в онлайн-оценку не входят.

Нужно для каждого \(k\) выдать:

- оценку \((\hat s_k,\hat v_k)\) и ковариацию;
- статус \(\{\mathrm{UNINITIALIZED},\mathrm{OK},\mathrm{DEGRADED},\mathrm{LOST}\}\);
- калибруемый индикатор целостности (protection level и, отдельно,
  детерминированную скобку скорости);
- диагноз режима (качение, буксование, юз, отказ датчика, стоянка).

Класс задачи: проприоцептивное счисление пути на одномерном многообразии
рельса при нестационарном сцеплении и общей моде отказа измерений.
Это не SLAM и не плоская одометрия робота: измерение \(r\omega\) перестаёт
быть измерением \(v\) именно тогда, когда резерв нужен.

### 1.3 Чем измеряется успех

Работоспособность на записи организатора важнее нового фильтра на синтетике.
Критерии, которые двигают оценку:

| Критерий | Что показать |
| --- | --- |
| Соответствие кейсу | В фильтре нет GNSS/IMU/лидара; проверка `tools/eval/no_gnss_scan.py` |
| Работоспособность MVP | Прогон их bag, таблица против трёх baseline, видео топиков |
| Алгоритм | Идентифицированная физика + UKF + интервальная скобка + остаточный аппроксиматор |
| Новизна | Обучаемый остаток внутри физической модели и честная целостность, а не «новый UKF» |
| Быстродействие | p50/p99 шага ядра и цепочки ROS на их частоте |
| Внедрение | Теневой топик рядом с основной локализацией беспилотного трамвая |

Синтетика seed 42 остаётся регрессией, а не доказательством маршрута 10.

## 2. Что уже реализовано

Ядро `tramDR-0.0.11` — ковариационный scaled UKF, \(L=12\):

\[
x=[s,\,v,\,F_{bias},\,\log m,\,\log k,\,\log d_1,\ldots,\log d_6,\,\mathrm{logit}\,\mu]^\top.
\]

Рабочая точка \(\alpha=0.58\), \(\beta=2\), \(\kappa_{UT}=0\): \(\lambda=-7.9632\),
\(c=4.0368\), \(W^m_0=-1.97265\), \(W^c_0=+0.69095\), \(W_i=0.12386\).
Окно \(W^c_0\ge 0\) при \(\kappa=0\), \(\beta=2\): \(\alpha\in[0.51764,\,1.93185]\).
Политика достаточная, не необходимая для положительной полуопределённости.

Уже в коде и сохраняется:

- баланс сил: тяга с гиперболой мощности, Кулон \(\mu mg\), Дэвис, уклон,
  доля тормоза вне сцепления, PT1 и ограничение скорости изменения силы,
  останов на нуле при пассивном торможении и чистом выбеге
  (`tram_dr_localization/src/lib/plant.cpp`);
- SCA: медиана скоростей осей и инфлейшн по z-критерию (Palmer & Nourani-Vatani);
- робастный gain (Huber по диагонали \(S\)), NIS до робастизации;
- ZUPT, канал A без прямой коррекции по колёсам, защёлка целостности пути;
- априор Гаусса–Маркова на \(\log m\) со стационарной дисперсией \(R\);
- `project_pd` с отказом без санирования матрицы; атомарный откат шага;
- четыре ноды ROS 2 Humble; выход `nav_msgs/Odometry` несёт продольные \(s,v\),
  статус живёт на `/tram/diagnostics`;
- генератор с индивидуальной динамикой колёс и 1D-срезом Polach (11)+(4)+(9),
  отдельный от онлайн-модели (`tools/synth/generate.py`);
- 23 сценария синтетики, три baseline, независимый чекер конверта.

Открыто и не закрывается «ещё одним коммитом до bag»: полевая калибровка,
текст Положения, согласование публикации, WCET целевого контроллера, HIL.

## 3. Обзор литературы и перенос на задачу

Ниже — срез, собранный . Перенос ограничен: почти все рельсовые
работы 2023–2026 используют момент двигателя, ток, IMU или бализы. ТЗ даёт
ручку и \(\omega\). Методы, требующие запрещённого сенсора, остаются
контекстом доклада, а не кодом фильтра.

### 3.1 Одометрия и консенсус осей

Palmer & Nourani-Vatani (IROS 2018, arXiv:1803.02237) — EKF диаметров колёс
плюс Sensor Consensus Analysis на ICE. Наш SCA и состояния \(d_i\) — прямой
потомок; GPS-канал статьи нам запрещён. Промышленный патент EP 4 511 264 B1
и работа по восьмиосному локомотиву (Sci. Rep., 2025,
doi:10.1038/s41598-025-33173-6) берут в тяге самую медленную ось, в торможении
самую быструю. Для «Львёнка» (Bo-Bo, все оси моторные) медиана смещена при
частичном буксовании; порядковая статистика — следующий шаг, см. M3 и F3.

Смежные постановки, которые не копируются: GNSS/INS/одометрия ERTMS (CLUG2,
ION GNSS+ 2024), MEMS-INS без GNSS (Electronics 2024, doi:10.3390/electronics13224498),
визуальные и инерциальные виртуальные бализы (IEEE Access 2023,
doi:10.1109/ACCESS.2023.3236784). Последняя схема переносится только как
опциональная коррекция по остановкам, если организатор разрешит карту.

### 3.2 Сцепление колесо–рельс

Контакт. Polach (Wear 258, 2005, doi:10.1016/j.wear.2004.03.046) — формулы
(4), (9), (11), (12). В репозитории это 1D-срез генератора, не онлайн-UKF
и не CONTACT/FASTSIM. Kalker (1979, 1990) и FASTSIM остаются эталоном
генератора, не фильтра: жёсткость крипа \(\tau\sim 0.3\,\mathrm{ms}\) не
разрешается шагом 20 мс без неявного интегратора, который уже есть в
`tools/eval/plant_ref.py` и в фильтр не переносится.

Наблюдатели сцепления требуют момент или ток:

- возмущающий наблюдатель момента и антиюз на серии 205-5000 (Ohishi et al.,
  1999; Kadowaki et al., IEEE TIE 2007, doi:10.1109/TIE.2007.895135);
- UKF крипа и \(\mu\) по поведению тягового двигателя, модель Polach
  (Zhao, Liang, Iwnicki, VSD 2014, doi:10.1080/00423114.2014.891757);
- UKF условия сцепления для ограничения скорости скольжения (Pichlík, TVT 2018);
- PI-наблюдатель с LMI (VSD 2024, doi:10.1080/00423114.2024.2351032);
- онлайн-оценка \(\mu\) по силовому балансу колёсной пары с ошибкой до 5 %
  на HIL (CMES 2025).

Пока в записи нет тока или момента, \(\mu\) остаётся ограниченным состоянием
с шумом процесса. Называть его измерением сцепления нельзя.

Численные уровни. Сухой рельс \(\mu\sim 0.3\ldots 0.4\); чистый мокрый
ниже; служебное торможение пассажирского поезда требует коэффициент тяги
примерно \(0.03\ldots 0.09\). Лиственная плёнка на полномасштабном стенде
даёт максимум около \(0.01\), почти независимо от скорости и нагрузки
(Tribology International 2023, doi:10.1016/j.triboint.2023.108529); линейный
полномасштабный стенд устойчиво держит коэффициент ниже \(0.05\)
(Jaffe, White, Lanigan, Lewis, Proc. IMechE F 238(6), 2024). Текущий клип
\(\mu\in[0.05,0.5]\) (`kMuMin` в `types.hpp`) отрезает измеренный хвост и
завышает тормозную силу в несколько раз. Это опасная сторона ошибки:
модель останавливается раньше вагона, путь занижается.

### 3.3 Продольная динамика, масса, уклон

Уравнение движения с приведённой массой \(m(1+\gamma)\) — стандарт тяговых
расчётов. Для трамвайных вагонов \(1+\gamma\) порядка \(1.09\ldots 1.15\)
(Шевченко, Байрыева, 1986; метод выбега для \(w_0\)). В ядре \(\gamma=0\):
масштаб силы и инерции неразличимы, поэтому \(\gamma\) фиксируется профилем,
а не оценивается.

Совместная оценка массы и уклона: RLS с разными коэффициентами забывания
(Vahidi, Stefanopoulou, Peng, VSD 43(1), 2005) и карта уклона по повторным
проездом (Sahlholm, Johansson, CEP 2010). У нас \(F_{bias}\) — случайное
блуждание, которое поглощает и уклон, и ошибку тяги. Разделение возможно
только при повторных проездах одного \(s\) и разрешённой карте.

Тормоза уличного трамвая. BOStrab §36: две независимые системы, одна не
зависит от сцепления (магниторельсовый тормоз), песочницы; опасное торможение
с 70 км/ч — средняя задержка не ниже \(2.73\,\mathrm{m/s^2}\) (Anlage 2,
таблица 2). VDV TR Br, опираясь на EN 13452, ограничивает длительную
служебную задержку \(2.0\,\mathrm{m/s^2}\) из соображений стоящих пассажиров.
Наше \(a_{svc}=1.2\,\mathrm{m/s^2}\) — параметр двойника Combino, не норма.
`brake_nonadhesive_frac` включается только если запись показывает канал
экстренного торможения.

### 3.4 Фильтр, адаптация шума, робастность

Scaled UT — Julier (ACC 2002), Wan & van der Merwe. Square-root UKF
(van der Merwe, Wan, ICASSP 2001) и cubature KF (Arasaratnam, Haykin,
IEEE Trans. Autom. Control 54(6), 2009; в [refs.md](refs.md) ошибочно указан
TSP — исправить) численно устойчивее на длинных горизонтах. Переписывать
ядро в SR-UKF за двое суток без нового факта расходимости \(P\) не нужно:
posterior-вычитание \(KSK^\top\) остаётся отдельной проблемой, и политика
весов её не снимает (Kulikova, Kulikov, IFAC 2020).

Адаптация \(Q,R\): Mehra (IEEE TAC 1970); вариационный Байес для \(R\)
(Särkkä, Nummenmaa, IEEE TAC 54(3), 2009) и его нелинейное расширение
(Särkkä, Hartikainen, arXiv:1302.0681); совместная адаптация \(Q\) и \(R\)
(Huang et al., IEEE TAC 63(2), 2018). Обзор 2025 года сводит робастность и
адаптивность к одному вариационному фильтру на потере Стьюдента
(arXiv:2512.15419). Практический вывод для нас: вариационная адаптация
дисперсии канала — кандидат за флагом (M5), с обязательным сравнением против
текущих SCA и Huber. Sage–Husa без ограничения положительной определённости
в прод не ставится.

Тяжёлые хвосты: Стьюдент (Roth et al., ICASSP 2013), корентропия
(Chen et al., Automatica 76, 2017). Наш Huber по диагонали \(S\) — инженерный
аналог ограничения влияния; он не нормирует NIS. Отбор и гейтинг сжимают
статистику инноваций (Or, arXiv:2512.18508): поэтому NIS считается до Huber.

Мультимодельность. IMM (Blom, Bar-Shalom, IEEE TAC 33(8), 1988) и IMM-UKF
для смены сцепления (Control Engineering Practice 2024,
doi:10.1016/j.conengprac.2024.105901) статистически честнее нашего
`classify()`. Три параллельных UKF на 50 Гц укладываются в бюджет, но
матрица переходов нечем калибровать до появления размеченных юзов.
На хакатоне IMM остаётся дорожной картой; режимы остаются детекторами.

Ограничения на состояние. Проекция и усечение гауссианы (Simon, IET CTA
4(8), 2010; Garcia-Fernandez et al., IEEE TSP 60(7), 2012) позволяют вносить
в UKF кинематическую скобку \(v\in[L,U]\) без смены сигма-точечной схемы.
Интервальные наблюдатели (Gouzé, Rapaport, Hadj-Sadok, Ecological Modelling
133, 2000; обзор Ефимов, Раисси, Автоматика и телемеханика 77(2), 2016)
дают детерминированную гарантию при ограниченных возмущениях — то, чего
\(k\sqrt{P}\) не даёт.

Наблюдаемость. Ранговый критерий (Hermann, Krener, IEEE TAC 1977) и
эмпирический грамиан (Krener, Ide, CDC 2009) — способ показать жюри ядро
\((m,k)\), общий масштаб радиуса и неразличимость \(F_{bias}\) с уклоном,
а не объявлять его на словах.

Состоятельность. Chen, Heckman, Julier, Ahmed (FUSION 2018, «Weak in the
NEES?») — протокол, которым проверяется NEES после тюнинга. На двойнике
NEES\(_s\) сейчас \(0.002\ldots 0.03\) (слишком осторожно), на
`mismatch_r0` — около 200 (слишком уверенно).

### 3.5 Гибрид физики и обучения

Обзор Shlezinger, Revach et al. (IEEE Signal Processing Magazine, 2025;
arXiv:2410.12289) делит схемы на целевые и сохраняющие пространство
состояний. KalmanNet (Revach et al., IEEE TSP 70, 2022) учит коэффициент
Калмана при частично известной динамике. Для хакатона он не подходит:
нужны размеченные траектории, гарантия ковариации пропадает, бюджет времени
уходит в обучение.

Переносимый класс — остаток поверх номинальной физики:

- GP-UKF (Ko, Fox et al., Auton. Robots 27, 2009): гауссов процесс как
  модель прогноза, дисперсия процесса растёт с неопределённостью модели;
- осторожный MPC с GP (Hewing, Kabzan, Zeilinger, IEEE TCST 28(6), 2020);
- PERL (Communications in Transportation Research, 2025,
  doi:10.1016/j.commtr.2025.100166): прогноз = физика + выученный остаток,
  данных нужно меньше, чем чистому NN;
- обзор physics-informed ML (Karniadakis et al., Nat. Rev. Phys. 3, 2021).

На доступном объёме (одна-несколько поездок) непараметрический GP онлайн
дорог. Спецификация M4 — линейный по параметрам сплайновый остаток силы
с гребнем и диагональной неопределённостью, которая добавляется в \(Q\).
Это и есть «аппроксиматор» из текста ТЗ: он адаптивен, нелинеен по скорости
и остаётся внутри уравнений движения.

Чисто нейросетевые оценки скорости и детекторы буксования — ориентир для
сравнения на питче, не для ядра: CNN против адаптивного Калмана
(arXiv:2508.17096, 2025), wavelet+LSTM на годовых данных DMU
(Engineering Applications of AI 137, 109173, 2024). У них нет ковариации,
статуса и воспроизводимого контракта отказа.

### 3.6 Целостность

Защитный уровень фильтра — не риск целостности. Последовательный монитор
по инновациям с оценкой риска пропуска (Joerger, Pervan, JGCD 2013,
doi:10.2514/1.59480) и рельсовая раскладка риска CLUG2 (ION GNSS+ 2024,
doi:10.33012/2024.19760) требуют модели отказов и бюджета вероятности,
которых у хакатона нет. Честный перенос:

- overbounding эмпирических хвостов \(e/\sigma\) (DeCleene, ION GPS 2000);
- диаграмма Stanford: норма / misleading information / hazardously
  misleading information / недоступно (Tossaint et al., Navigation 54(2), 2007);
- конверт пути формы \(\pm(5\,\mathrm{m}+5\,\%\,s)\) как ориентир
  SUBSET-041 §5.3.1.1, уже реализованный чекером против GT. Это не
  применение ETCS к трамваю.

### 3.7 Реальное время ROS 2

Жёсткое реальное время всего графа ROS 2 не выводится из фиксированных
массивов ядра. Измерять: гистограмму шага `replay_ukf`; сквозную задержку
«метка колеса → публикация» в ноде; при возможности — `ros2_tracing`
(Bédard, Lütkebohle, Dagenais, IEEE RA-L 2022) и семантику цепочек
(Teper, Betz, Günzel, von der Brüggen, Chen, RTSS 2022). Голодание
многопоточного исполнителя (Teper et al., EMSOFT 2024) — аргумент оставить
оценщик на однопоточном исполнителе с отдельной группой колбэков.

### 4.1 Контракт входа

ТЗ обещает ручку и одометрию. Ядро считает отсутствующий тормоз отказом:
`brake_missing_s_ > notch_lost_s` (2 с) даёт LOST в `Ukf::classify`

в NaN, если топика нет (`tools/eval/bag_to_jsonl.py`), а `replay_ukf` считает
нечисловой тормоз невалидным.

задаёт силу обратного знака; ZUPT требует \(|n|<0.05\); детектор юза смотрит
на `brake > 0.15`. Вагон с одной ручкой «ход / тормоз» на стоянке получит

Дополнительные ловушки шкалы, каждую закрывать тестом конвертера:

  проценты \([-100,100]\) насыщаются;
- \(|\omega|>80\,\mathrm{rad/s}\) отбрасывается (`kOmegaAbsMax` в `types.hpp`);
  обороты в rpm попадают в этот отсев;
- одноканальная одометрия дополняется NaN до `n_wheels` и вечно считается
  неполным пакетом;
- устаревание команд 0.25 с зашито в конвертере; топик «по изменению»
  обнулит ручку через 0.25 с.

### 4.3 Оценка

Ковариация радиусов диагональна: после инициализации дисперсия \(\log d_i\)
равна \(10^{-4}\). Дисперсия общего масштаба тогда \(\sigma_c\approx 1\,\%/\sqrt{n}\).
Реальная общая ошибка без калибровки — проценты и десятки процентов, и в
\(P_{ss}\) она почти не видна. Это механизм `mismatch_r0` (HMI 0.515 при
статусе OK). Спецификация — M2.

SCA, Huber и множитель `r_common_mode` — три эвристики, не модель правдоподобия.
NIS после них не \(\chi^2\). CUSUM не калиброван.

\(F_{bias}\) как случайное блуждание объясняет уклон, ошибку тяги и ветер
одной силой. Структурный остаток — M4.

\(b_s=\kappa_{cut}|v|T_{hold}\) — запас детектора, не верхняя граница
произвольного юза. Детерминированная скобка — M3.

### 4.4 Что сознательно не делается на хакатоне

- Перепись в square-root UKF и Joseph-форма.
- IMM из трёх фильтров.
- Полная связанная модель колесо–кузов внутри UKF (она живёт в генераторе).
- KalmanNet, LSTM, end-to-end CNN.
- Заявления о SIL, THR, CENELEC, ETCS.
- Подстановка OSINT-уклона Строгинского подхода в ноду.

## 5. Математические спецификации

Флаги по умолчанию выключены или эквивалентны текущему ядру. Включение —
после теста и строки в CHANGELOG.

### M1. Номинальная динамика

\[
\dot s = v,
\]
\[
m(1+\gamma)\,\dot v = F_c - f F_b - R(v) - mg\,i(s) - F_{bias} + \phi^\top\theta + w_v.
\]

\[
F_c = \mathrm{clip}\big(F_{cmd}-(1-f)F_b,\,-\mu mg,\,\mu mg\big),
\]
\[
F_b = b\, m\, a_{svc}(v)\, \mathrm{sgn}(v)\ \mathbf{1}_{|v|>v_\varepsilon}.
\]

\(F_{cmd}\) — характеристика \(F^\star(n^+,v)\), пропущенная через транспортное
запаздывание \(T_d\), PT1 с постоянной \(\tau\) и ограничение
\(|\Delta F|\le m j_{max}\Delta t\). \(n^+=\max(n,0)\). При одной ручке
электрический тормоз — диссипативный член \(F_b\), а не отрицательная тяга:
на стоянке он нулевой.

Характеристика тяги с третьей зоной (включать, только если данные показывают
излом):

\[
F^\star = k\, n^+ F_0 \begin{cases}
1, & |v|\le v_b,\\
v_b/|v|, & v_b<|v|\le v_2,\\
v_b v_2 / v^2, & |v|>v_2.
\end{cases}
\]

\(R(v)=\mathrm{sgn}(v)(A_d+B_d|v|+C_d v^2)\) вне \(v_\varepsilon\), ноль внутри.
Измерение в режиме качения \(\omega_i = v/(r_0 d_i)+\varepsilon_i\). Крип
\(r\omega-v\) порядка 0.5–1.5 % — поправка второго порядка после идентификации.

\(\gamma\) для моторного трамвайного вагона фиксируется профилем в диапазоне
литературы, с номиналом \(0.12\). Он не состояние фильтра: в тяге наблюдается
\(m(1+\gamma)\), в торможении с компенсацией загрузки — \(a_{svc}/(1+\gamma)\).

Границы \(\mu\) становятся параметрами `mu_min`, `mu_max`. Нижняя граница
по умолчанию для городского осеннего рельса — \(0.02\), не \(0.05\). Смена
умолчания меняет логит-координату и требует регрессии `xi_to_phys` плюс
пересчёта синтетики, если включена в двойнике.

### M2. Общий масштаб радиуса

Разложение \(\log d_i = c + e_i\), \(c\sim\mathcal N(0,\sigma_c^2)\),
\(e_i\sim\mathcal N(0,\sigma_e^2)\) независимы. На живых каналах

\[
P_{\ell\ell}=\sigma_c^2\mathbf{1}\mathbf{1}^\top+\sigma_e^2 I.
\]

Прогноз пути тогда имеет член \(\sigma_s \gtrsim \sigma_c\, s\). Защитный
уровень сравнивается с порогом \(AL=5+0.05 s\):

\[
s^\star = \frac{5}{k_{over}\sigma_c - 0.05}, \qquad k_{over}\sigma_c>0.05.
\]

При \(k_{over}=2.5\) и \(\sigma_c=0.03\) получается \(s^\star=200\,\mathrm{m}\):
некалиброванный общий масштаб сам переводит оценку в DEGRADED задолго до
опасной ошибки. После калибровки по GT \(\sigma_c\le 0.005\), деградации нет.
Параметры `radius_common_sigma`, `radius_indiv_sigma`. Умолчание
\(\sigma_c=0\), \(\sigma_e=0.01\) воспроизводит сегодняшнюю диагональ.

Тесты: ковариация остаётся SPD; на длинном выбеге наклон \(\sqrt{P_{ss}}(s)\)
близок к \(\sigma_c\); сценарий общего масштаба с честным \(\sigma_c\)
уходит в DEGRADED, а не в OK с маленькой \(P_{ss}\).

### M3. Интервальный наблюдатель скорости

Фазы по командам, с гистерезисом: тяга \(\mathcal T\), торможение \(\mathcal B\),
выбег \(\mathcal C\).

Допущения, которые публикуются рядом с выходом:

1. В тяге моторная ось удовлетворяет \(r_i\omega_i \ge v\).
2. В торможении заторможенная ось удовлетворяет \(r_i\omega_i \le v\).
3. На выбеге \(|r_i\omega_i-v|\le \varepsilon_c v+\eta\).
4. \(r_i\in[r^-,r^+]\) из калибровки (паспорт \(\pm\) допуск до идентификации).
5. Среди каналов, прошедших SCA, не больше одного ложного.
6. Ускорение ограничено известными \(\bar a_{acc}\), \(\bar a_{dec}\).

Порядковые статистики живых каналов \(\omega_{(1)}\le\cdots\le\omega_{(n)}\).
Нижняя граница (опасная сторона при торможении — занижение пути):

\[
L_k=\max\Big(L_{k-1}-\bar a_{dec}\Delta t,\ \ r^-\omega_{(n-1)}-3\sigma_\omega r^-\Big).
\]

Второе слагаемое обновляется в \(\mathcal B\) и \(\mathcal C\); на выбеге
домножается на \(1-\varepsilon_c\). Скорость убывания: в торможении
\(3.5\,\mathrm{m/s^2}\) (запас над опасным торможением и спуском),
в тяге и на выбеге \(R_{max}/m+g i_{max}\approx 0.5\,\mathrm{m/s^2}\).

Верхняя граница:

\[
U_k=\min\Big(U_{k-1}+\bar a_{acc}\Delta t,\ \ r^+\omega_{(2)}+3\sigma_\omega r^+,\ v_{design}\Big).
\]

Второе слагаемое обновляется в \(\mathcal T\) и \(\mathcal C\). Скорость роста:
в тяге \(2\,\mathrm{m/s^2}\), иначе \(g i_{max}\approx 0.4\,\mathrm{m/s^2}\).

Путь интегрируется трапецией по границам:

\[
s^{lb}_k = s^{lb}_{k-1}+\min(L_{k-1},L_k)\Delta t,
\qquad
s^{ub}_k = s^{ub}_{k-1}+\max(U_{k-1},U_k)\Delta t.
\]

Режимы флага `interval`:

- `monitor` — флаг диагностики, если \(\hat v\pm 3\sigma_v\) не пересекает \([L,U]\);
- `truncate` — усечение гауссианы UKF (формулы ниже);
- `integrity` — публикация \([s^{lb},s^{ub}]\) потребителю.

Усечение \(v\ge L\). При \(\alpha=(L-\mu)/\sigma\), \(\lambda=\varphi(\alpha)/(1-\Phi(\alpha))\):

\[
\mu'=\mu+\sigma\lambda, \qquad \sigma'^2=\sigma^2(1+\alpha\lambda-\lambda^2).
\]

Усечение \(v\le U\). При \(\beta=(U-\mu)/\sigma\), \(\rho=\varphi(\beta)/\Phi(\beta)\):

\[
\mu'=\mu-\sigma\rho, \qquad \sigma'^2=\sigma^2(1-\beta\rho-\rho^2).
\]

Перенос на остальные координаты стандартный:

\[
x' = x + \frac{P_{xv}}{P_{vv}}(\mu'-\mu),
\qquad
P' = P - \frac{P_{\cdot v}P_{v\cdot}}{P_{vv}}\Big(1-\frac{\sigma'^2}{\sigma^2}\Big).
\]

Применять только при активном ограничении (\(\alpha>-3\) или \(\beta<3\)),
затем существующий `project_pd`. При умолчании `interval=off` шаг UKF
байт-в-байт прежний.

Приёмка на синтетике: при выполнении допущений доля кадров с \(v_{gt}\notin[L,U]\)
равна нулю на сценариях без внесённого нарушения допущений. Нарушение
допущения (все оси в юзе, ложный радиус вне \([r^-,r^+]\)) обязано поднимать
статус, а не молча сужать скобку.

### M4. Аппроксиматор остаточной силы

Остаток строится офлайн на train, где есть \(v_{gt}\) и нет юза
(\(|r\bar\omega-v_{gt}|\) ниже порога):

\[
r_k = m(1+\gamma)\,\hat a^{gt}_k - F_{phys}(n_k,b_k,v_k;\hat\theta_{phys}).
\]

\(\hat a^{gt}\) — производная Савицкого–Голея, окно около 1 с.
Базис: кубические B-сплайны скорости (узлы 0, 2, 5, 10, 15, 20 м/с)
на четыре режима \(\{1, n^+, n^-, b\}\), плюс лаг команды \(n_{k-d}\),
где \(d\) оценено кросс-корреляцией. Итого порядка 40 коэффициентов.

Гребень P-сплайна (Eilers, Marx, Statistical Science 1996):

\[
\hat\theta=(\Phi^\top\Phi+\lambda D^\top D)^{-1}\Phi^\top r,
\]

\(\lambda\) — блочная кросс-валидация по поездкам train.
\(\Sigma_\theta \approx \hat\sigma^2 (\Phi^\top\Phi+\lambda D^\top D)^{-1}\).

Онлайн \(\phi(v,n,b)^\top\hat\theta\) — десятки операций. Вне оболочки данных
плечо \(h=\phi^\top(\Phi^\top\Phi+\lambda D^\top D)^{-1}\phi\) сравнивается
с порогом: выше порога остаток отключается и сила возвращается к номинальной
физике. Дисперсия \(\phi^\top\Sigma_\theta\phi\) добавляется в интенсивность
\(w_v\) на этом шаге. Медленная адаптация между поездками по-прежнему сидит
в \(F_{bias}\); отдельные состояния «масштаб тяги / масштаб тормоза» —
только если валидация показывает остаточный дрейф.

Тот же остаток обязан стоять в канале A. Иначе канал A сравнивает колёса
с худшей моделью, чем основной фильтр, и детектор юза смещается.

Приёмка: на сценарии `model_mismatch` ошибка прогноза по одной ручке на
горизонте 10 с падает относительно чистой физики; при выключенном флаге
синтетический e2e совпадает с базовой линией.

### M5. Вариационная адаптация дисперсии канала

По Särkkä & Nummenmaa (2009), независимо по живым осям, флаг `r_adapt`.

Прогноз гиперпараметров обратного гамма-распределения:
\(\alpha^-=\rho\alpha\), \(\beta^-=\rho\beta\), \(\rho\in(0,1]\).
Две-три итерации: \(R_j=\beta_j/\alpha_j\); обычное обновление UKF;
\(\alpha_j=\alpha_j^-+1/2\),
\(\beta_j=\beta_j^-+\tfrac12 \mathbb E[(z_j-h_j)^2]\) по апостериорным
сигма-точкам. \(R_j\) зажимается в \([R_{min}, R_{max}]\).
Отчётный NIS считается по номинальному \(R\), как сейчас — по сырому \(S\).

Включение только после A/B на val против текущих SCA+Huber. Если NEES или
HMI хуже, флаг остаётся выключенным и это пишется в отчёте.

### M7. Тюнинг шумов

### M9. Калибровка целостности

По кадрам OK на val строится нормированная ошибка \(z=e_s/\sigma_s\).
Множитель overbounding \(\kappa_{ob}\) — минимальный, при котором гауссиана
\(\mathcal N(0,(\kappa_{ob}\sigma)^2)\) покрывает эмпирические квантили хвоста.
Публикуемый PL использует \(\kappa_{ob}\). Скобка M3 публикуется отдельно
и в этот множитель не замешивается.

Диаграмма Stanford: оси «ошибка» и «PL», области норма / MI / HMI /
недоступно. Порог опасной ошибки — конверт чекера, если заказчик не задал
свой. Никакого перевода \(k\sigma\) в интенсивность опасных отказов в час.

уже считается, и разность «stamp входа → stamp публикации» на одном и том
же времени симуляции. Исполнитель однопоточный. В горячем цикле нет

### M11. Остановки как редкая коррекция

Только с явным разрешением организатора и флагом `stop_update`.

Условие: ZUPT удерживается не короче \(T_d\), и существует остановка \(j\)
с \(|\hat s-s_j|\le g\sqrt{P_{ss}+\sigma_{map}^2}\). Тогда псевдоизмерение
\(z=s_j\), \(R=\sigma_{stop}^2\) порядка \((3\ldots 5\,\mathrm{m})^2\).
Кросс-ковариация \(P_{s,d}\) подтягивает общий масштаб радиуса. Остановка
у светофора отличается выдержкой и, если он есть, сигналом дверей.
По умолчанию флаг выключен. В докладе — абляция «с коррекцией / без».

Карта уклона \(i(s)\) в ноду попадает только из профиля, построенного по
их GT (`tools/eval/profile_from_bag.py` или оценка по повторам), и тоже
за флагом. Оценка 25–40 ‰ Строгинского подхода остаётся сценарием генератора.

## 6. Протокол эксперимента

Протокол фиксируется до просмотра test. Это защита от подгонки, которую
жюри с опытом данных (SberAI Lab, центр НТИ) узнаёт сразу.

1. Единица разбиения — поездка или, при одной поездке, блок не короче 10 мин.
   Соседние 50 Гц кадры независимыми испытаниями не считаются.
2. Train: идентификация M1/M4, тюнинг M7. Val: выбор флагов, \(\kappa_{ob}\),
   ранний останов. Test: один прогон, без изменения параметров.
3. Состав методов фиксирован: naive \(r\omega\); интеграл номинальной физики;
   комплементарный фильтр; UKF с паспортом; UKF после идентификации;
   UKF + остаток; UKF + интервальная скобка. Добавлять метод после просмотра
   test нельзя.
4. Отказы вносятся копией `inject` поверх val и test одинаковым YAML и seed.
   Набор: рампа буксования всех осей 20 и 50 %; юз с циклами блокировки
   0.4 с; залипание одной оси; NaN на всех осях; масштаб 0.97 на одной оси;
   задержка \(\omega\) 50 и 100 мс. Определение каждого отказа — в репозитории
   до T0.
5. Отчёт хранит commit, хеш конфигурации, хеш входа, команду и сырой JSON.
   Таблица без этой четвёрки в README не переносится.
6. Отрицательный результат остаётся в разделе ограничений. Прятать
   `mismatch_r0` и провал на реальном юзе нельзя: для этого жюри и читает
   приложения.

10. Формат сдачи: допустим ли приватный репозиторий с доступом жюри, нужно ли видео.

## 12. Определение готовности к загрузке

Загрузка допустима, когда одновременно верно следующее.

1. На записи организатора есть таблица M8 для методов из §6, с commit и хешами.
2. Нода поднимается в Docker на этой записи и публикует оба топика; статус
   на чистом выбеге не LOST из-за отсутствующего тормоза.
3. При выключенных новых флагах синтетический e2e совпадает с базовой линией
   фазы 0 либо отличие объяснено и пересчитано.
4. CTest, санитайзеры и Python-наборы зелёные на том commit, который сдаётся.
5. Доклад называет худший режим и отрицательный контроль вслух.
6. В архиве нет записей организатора и нет утверждений о сертификации.
