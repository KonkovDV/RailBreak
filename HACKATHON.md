## 2. Что входит в контур сдачи

Резервный 1D-контур позиционирования:
* **Входные сигналы:** положение контроллера тяги $n\in[-1,1]$, команда торможения $b\in[0,1]$, угловые скорости колёс $\omega$ (рад/с).
* **Выходные сигналы:** путевая координата $s$, продольная скорость кузова $v$, ковариации, статус (`OK / DEGRADED / LOST`), уровень защиты $PL_s$.
* **Чистота контура:** в фильтре нет подписок на GNSS, оптический поток, лидар и ИНС (проверка: `tools/eval/no_gnss_scan.py`).
* **Топик `/tram/fix`:** проекция пути на полилинию остановок со статусом `STATUS_NO_FIX`.

## 3. Обработка rosbag2-записи Организатора

```bash
# 1. Топики и типы → customer_topics.yaml (адаптер и оценщик)
python tools/eval/inspect_bag.py data/bags/run01 \
  --write-yaml tram_dr_localization/config/customer_topics.yaml

# 2. Опционально, оффлайн: профиль h(s) по GT/лидару. Не вход фильтра.
python tools/eval/profile_from_bag.py data/bags/run01 --out data/route_10_profile.csv

# 3. Реплей через фильтр и независимый чекер конверта
python tools/eval/run_bag.py data/bags/run01 \
  --ukf standalone/build/replay_ukf \
  --route tram_dr_localization/config/route_10.yaml \
  --vehicle tram_dr_localization/config/vehicle_lvenok_moscow.yaml \
  --baselines
```

## 5. Состояние решения к сдаче (на 06.09.2026)

Ядро сдаётся в версии `tramDR-0.0.7`. Полный реестр находок и их статус —
[`CHANGELOG.md`](CHANGELOG.md); что именно исполнялось численно, а что только
выведено — [`docs/verification.md`](docs/verification.md).
Мы не утверждаем «ошибок нет»: ниже граница проверенного.

Пять пунктов оставлены открытыми сознательно и вынесены в
[issue #3](https://github.com/KonkovDV/RailBreak/issues/3):

| Пункт | Суть | Почему не закрыт к сдаче |
| --- | --- | --- |
| `F-08` | `validate_ukf` не проверяет $W_c^{(0)}\ge 0$: при смене $\beta$ без пересчёта $\alpha$ вес станет отрицательным молча | алгебра закреплена независимым тестом `test_ut_weights_psd`; правка валидатора меняет публичный контракт параметров |
| `F-09` | `project_pd` при нефинитном входе выходит досрочно, не санируя матрицу | дыру закрывает атомарный откат шага; сама санация ковариации — отдельное проектное решение |
| `F-10` | гейт стоянки частично опирается на собственную оценку $\lvert v\rvert$ | потолок последствий оценён ($\approx 22$ с, $\approx 10$ м); ортогональное свидетельство требует нового входа |
| `F-13b` | метрики сняты на `tramDR-0.0.6` | пересчёт — это прогон `generate.py` → `replay_ukf` → `run_e2e.py` → `score.py` в среде с CMake и Python |
| `F-17` | `state_estimator_node.cpp` не валидирует вход и зажимает отрицательный $\Delta t$ | ядро такой вход отклоняет и откатывает шаг; правка узла не проверялась запуском (нет `rclcpp` в среде проверки) |

Чего в репозитории нет и что не заявляется: сертификация SIL/CENELEC, прогон на
записи Организатора, полевая калибровка $r_0$ и $m_0$ по bag, запуск узлов
ROS 2 и пересчёт метрик на 0.0.7. Оценки геометрии Строгинского моста (уклон
25–40 ‰) — OSINT для генератора сценариев, а не данные изысканий и не вход фильтра.
